# Project Polaris

Project Polaris is the sample solution used throughout this book to demonstrate **AI-assisted development** with Microsoft Power Pages, Dataverse, Power Automate, GitHub Copilot, ChatGPT, and Microsoft Copilot.

The project represents a **Community Grants Management Portal** that allows community organisations to:

* Apply for grants
* Upload supporting documents
* Track application progress
* Receive notifications

Internal staff use Dataverse and a model-driven application to review, assess, approve, and manage grant applications.

## Project Contents

This repository contains artefacts created throughout the software development lifecycle, including:

* Discovery and requirements documents
* Architecture and security designs
* AI conversations and reusable prompts
* Specialised AI agent definitions
* Testing artefacts
* Power Pages source files and supporting code

## Purpose

The purpose of Project Polaris is to demonstrate how different AI tools and specialised AI agents can support:

* Business analysis
* Solution architecture
* Development
* Testing
* Documentation
* Deployment and delivery

Human judgement, validation, and accountability remain at the centre of every stage of the implementation.
